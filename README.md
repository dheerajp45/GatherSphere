# GatherSphere

**A complete ecosystem for organizing and participating in events.**

---
## Status

> 🚧 Currently under active development. Features are being built and things may change.

---
## What is GatherSphere?

GatherSphere is a modern event management platform designed to make hosting and attending events as simple as possible.

The platform is built around one core idea — creating events should be powerful and flexible for hosts, while attending events should be effortless for participants.

---

## Core Philosophy

**Hosting requires an account. Attending does not.**

Anyone can register for an event without creating a GatherSphere account. Just open the event page, fill in your details, and you're in.

For hosts, a full-featured dashboard gives complete control over events, registrations, and attendees.

---

## Features

### For Hosts
- Create and manage events — offline or online
- Set capacity limits and registration deadlines
- Choose between auto-approval or manual approval for registrations
- Manage all registrations from a dedicated panel
- Track attendance

### For Participants
- Browse and discover events without an account
- Register for events in seconds — just name, email, and phone
- Past registrations automatically link to your account if you sign up later with the same email

### Events
- Public event pages with shareable links
- Support for both offline (venue) and online (meeting link) events
- Event status system — Draft, Published, Registration Closed, Completed, Cancelled
